# Linear Models
These optimization problems are solved exactly (or approximately, e.g., kernel) through solvers.

See the {doc}`f-divergence DRO notebook <../api/notebooks/f_dro_tutorial>` for
standard and partial-shift linear examples.

See the {doc}`Wasserstein DRO notebook <../api/notebooks/WassersteinDRO_tutorial>`
for linear classification, regression, and robust-satisficing examples.

See the {doc}`Group DRO notebook <../api/notebooks/groupdro_tutorial>` for an
end-to-end linear and neural example.

See the {doc}`kernel DRO notebook <../api/notebooks/kernel_dro_tutorial>` for
an MMD-DRO example and ambiguity-set kernel selection guidance.

See the {doc}`Bayesian DRO notebook <../api/notebooks/param_dro>` for
frequentist and Bayesian parametric examples.

See the {doc}`mixed-distance DRO notebook <../api/notebooks/mixed_dro_tutorial>`
for Sinkhorn, MOT, OR-WDRO, and Holistic DRO examples.
